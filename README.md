# Weld Defect Detection & Classification

Deep learning pipeline for automated weld quality inspection: compares
**ResNet-18**, **MobileNetV3**, and **YOLOv8** for classifying weld
surface defects, and deploys the best-performing model (YOLOv8) for
image, folder, and live-camera inference.

Dataset: [Weld-Defect-Dataset](https://github.com/Linkesh-K-V/Weld-Defect-Dataset)
(Pascal VOC format).

## Project Structure

```
weld-defect-detection/
├── models/                  # trained weights (.pt) — generated, not tracked in git
├── dataset/
│   ├── train/                # per-class image folders — generated by prepare_dataset.py
│   └── val/
├── src/
│   ├── config.py             # shared paths & hyperparameters
│   ├── prepare_dataset.py    # raw VOC dataset -> per-class train/val folders
│   ├── train_cnn_models.py   # trains ResNet-18 + MobileNetV3
│   ├── train_yolo.py         # trains YOLOv8 classification
│   ├── evaluate_models.py    # accuracy/precision/recall/F1, confusion matrix, comparison chart
│   └── yolo_inference.py     # image / folder / live-camera inference with the final model
├── results/                  # confusion matrices, reports, comparison chart — generated
├── requirements.txt
└── README.md
```

git clone <this-repo>
cd weld-defect-detection
python -m venv .venv

## Usage

**1. Prepare the dataset** (converts the raw VOC-format download into
per-class train/val/test folders, using the repo's own original
train/val/test split):

```bash
python src/prepare_dataset.py --raw_dir "path/to/Weld-Defect-Dataset"
```

The real defect labels in this dataset are `good`, `Surface_pores`,
`wrong_size`, `Not_fully_soldered`, and `crater` (a `Weld` box marking
the weld-seam region is excluded by default — pass `--keep_labels Weld`
to include it). Images with multiple defects get a combined folder name
like `Surface_pores;wrong_size`, giving ~15 distinct classes overall.

> **Note:** class balance is uneven — a few combos have very few images
> (e.g. `crater` alone = 2, `Surface_pores` alone = 4). Per-class
> precision/recall for those will be noisy no matter how well the model
> trains; the confusion matrix from `evaluate_models.py` will show
> exactly which ones.

**2. Train the models:**

```bash
python src/train_cnn_models.py      # ResNet-18 + MobileNetV3
python src/train_yolo.py            # YOLOv8 classification
```

**3. Evaluate and compare:**

```bash
python src/evaluate_models.py --model all               # against dataset/val
python src/evaluate_models.py --model all --split test   # against the held-out test set
```

Outputs confusion matrices, classification reports, and a comparison
bar chart to `results/`.

**4. Run inference with the final model (YOLOv8):**

```bash
python src/yolo_inference.py --source path/to/image.jpg
python src/yolo_inference.py --source path/to/folder
python src/yolo_inference.py --camera
```

## Results

Three algorithms were trained and evaluated on accuracy, precision,
recall, and F1-score. YOLOv8 achieved the best overall performance and
fastest inference speed, and was selected as the deployed model for
image, folder, and live-camera weld inspection.

| Model        | Notes                                             |
|--------------|----------------------------------------------------|
| ResNet-18    | Strong feature extraction, good baseline accuracy   |
| MobileNetV3  | Lightweight, fastest training, slightly lower accuracy |
| YOLOv8       | Highest accuracy, real-time capable — final model   |

See `results/model_comparison.png` after running `evaluate_models.py`
for exact numbers on your training run.
